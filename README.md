# My Tab

My Tab is a fast, customizable Chrome new-tab extension built with TypeScript, vanilla DOM APIs, and Tailwind CSS. It replaces the default new-tab page with a personal dashboard for quick access to sites and bookmarks.

## Overview

- Search the web with selectable search engines and autocomplete suggestions.
- Organize favorites, browser bookmarks, and folders in configurable grid layouts.
- Page through large collections with mouse controls or keyboard navigation.
- Customize the dashboard with wallpapers, clock preferences, density controls, and other settings.
